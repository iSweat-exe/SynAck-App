# Journal des changements

Toutes les évolutions notables de SynAck sont notées ici, version par version. Le format suit
[Keep a Changelog](https://keepachangelog.com/fr/1.1.0/) et le projet suit le
[versionnage sémantique](https://semver.org/lang/fr/) : `MAJEUR.MINEUR.PATCH`. Tant que la version
commence par `0.`, l'application est en pré-alpha et tout peut encore changer.

Le texte d'une version est repris tel quel dans la note de sa publication GitHub et affiché dans
l'application quand une mise à jour est proposée : il est écrit pour les élèves, pas pour les
développeurs.

## [0.1.0] - 2026-10-21

Première version.

### Ajouté

- 15 exercices de code en Python et en JavaScript, vérifiés par des tests cachés tirés au hasard à
  chaque validation.
- Les protocoles réseau (HTTP, HTTPS, TLS, DNS, TCP, UDP, SSH, IPC) expliqués avec des schémas animés
  et validés par un quiz.
- Connexion avec GitHub ou Discord, progression enregistrée sur ton ordinateur.
- Niveau, XP et pièces gagnés en résolvant des exercices, et une boutique (achats bientôt).
- Thème clair et sombre, fil d'Ariane, page de profil et questionnaire de bienvenue.
- Mises à jour automatiques depuis GitHub.
